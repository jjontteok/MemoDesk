# MemoDesk 설계 (1차)

> 2026-10-14 초안. content-pipeline 의 **차시 작업대**(`lesson_desk.py`)에서 교과 콘텐츠 전용이 아닌 부분만 뽑아,
> 아무 폴더(프로젝트)에나 쓸 수 있는 도구로 새로 만든다(방법 A — 코어를 새로 뽑기).
> 이 문서를 확인받은 뒤 코드를 옮긴다.

## 1. 무엇을 하는가

```text
[+ 프로젝트 추가] 이름 · 경로
      ↓
사람: 프로젝트 카드에 메모 적기(캡처 붙이기) ─▶ 대기열
      ↓
처리기(프로젝트마다 하나): 위에서부터 집음 → 작업 전 백업 → AI 가 그 경로의 파일을 고침
      ↓
성공: '확인 대기' + 한 줄 요약     실패 · 멈춤: 그 작업이 바꾼 것만 되돌리고 '열림'
      ↓
사람: 결과 보고 [완료] / [보완해서 다시 맡기기]
```

- **프로젝트 = 이름 + 경로 하나.** 대기열 · 메모 · 기록은 프로젝트마다 따로다.
- 각자 PC 에 설치해서 쓴다(`http://127.0.0.1:<포트>`, Windows 우선). 로그인 · 권한은 없다.
- AI 는 로컬에 설치 · 로그인된 CLI 를 부른다 — 클로드(`claude`), 2차부터 코덱스(`codex`).

## 2. 범위

| | 1차 | 2차 | 3차 |
|---|---|---|---|
| 프로젝트 추가 · 이름 · 경로 · 묶음(태그) · 지우기 | ✅ | | |
| 메모 적기 · 캡처 붙이기 · 대기열 순서 바꾸기 · 글 고치기 | ✅ | | |
| 처리기 · 백업 · 되돌림 · 꺼졌다 켜질 때 복구 | ✅ | | |
| 코드 메모 → 클로드 | ✅ | | |
| 결과(배지 · 한 줄 요약 · 자세히) · [완료] · [다시 맡기기] · [보완해서 다시 맡기기] | ✅ | | |
| [이번 작업 끝나면 멈춤] · [지금 멈춤] | ✅ | | |
| 알림(Windows) · 실패 이유 · AI 사용량 · 모델 고르기 | ✅ | | |
| 그림 · 검증 메모 → 코덱스 (코드 줄 ∥ 그림 줄 병렬) | | ✅ | |
| 프로젝트별 **빌드 · 검사 명령**, 대기열이 끝나면 자동 빌드, 빌드 지점 | | ✅ | |
| git 레포는 git 으로 백업(아래 5장) | | ✅ | |
| 지금 차시 작업대를 MemoDesk 위의 **gyo6 프리셋**으로 옮기기(음성 넣기 · 커밋 전 점검 · 수정 요청서는 플러그인) | | | ✅ |

**1차에서 하지 않는 것**: 서버 하나를 여럿이 같이 쓰기, 원격 접속, 커밋 · 푸시 · 배포(사람이 한다).

## 3. 용어

| 말 | 뜻 |
|---|---|
| 프로젝트 | 이름 · 경로 · 묶음 · 설정. AI 가 고칠 수 있는 범위는 **그 경로 안**뿐 |
| 메모 | 사람이 적은 할 일 하나. 번호(`M01` …)는 지워도 다시 쓰지 않는다 |
| 종류 | 1차는 `코드`(클로드) · `사람`(AI 에게 안 맡김). 2차에 `그림` · `검증` · `빌드 지점` |
| 줄(lane) | AI 별 실행 줄. 줄마다 한 번에 한 작업 |
| 작업 | 처리기가 한 번에 집은 **같은 종류 연속 메모 묶음** 하나. 작업 번호 = 시각(`20261014-153000`) |
| 상태 | 대기 → 처리 중 → 확인 대기(된 것) / 열림(못 한 것) → 완료 |

## 4. 구조

```text
MemoDesk/
  memodesk.py              서버 — HTTP · API · 화면 파일 · 시작/복구
  memodesk/
    projects.py            프로젝트 목록 · 추가 · 수정 · 지우기(경로 검사)
    notes.py               메모 저장 · 상태 전이 · 대기열 순서 · 묶음 고르기   ← lesson_notes.py 에서
    runner.py              처리기 · 줄 · 작업 실행 · 백업/되돌림 · 복구 · 멈춤 ← lesson_desk.py 에서
    agents/claude_fix.py   코드 메모 → 클로드 호출 · 결과 정리               ← desk_fix.py 에서
    ai_clients.py          클로드(·코덱스) CLI 호출 · 모델 · 강도 · 계정      ← codex_client.py 에서
    usage.py · notify.py · failures.py                                      ← 같은 이름의 모듈에서
  prompts/fix_system.md    범용 지시(아래 6장)
  web/index.html · common.css · common.js                                  ← lesson_desk.html · desk_common.* 에서
  tests/
  data/                    ← PC 마다 다른 기록. git 에 안 올린다(.gitignore)
    config.json            포트 · 모델 · 강도 · 코덱스 계정 폴더 · 프로젝트 목록
    projects/{id}/
      notes.json · jobs.jsonl · jobs/ · backup/ · attachments/ · removed/ · orphans/ · usage-log.jsonl
```

- 프로젝트 id 는 추가할 때 이름에서 만든다(영문 · 숫자 · `-`, 겹치면 뒤에 번호). **경로가 바뀌어도 id 는 그대로** — 기록이 id 에 묶인다.
- 기록은 프로젝트 폴더가 아니라 `data/` 에 둔다(남의 레포를 더럽히지 않는다 — 차시 작업대에서 배운 것).

## 5. 백업 · 되돌림

차시 작업대는 작업 전에 **차시 폴더 전체**를 복사했다. 차시 폴더는 작지만 범용 프로젝트는 클 수 있다.

| 방식 | 장점 | 단점 | 언제 |
|---|---|---|---|
| **폴더 복사**(제외 목록 · 크기 상한) | git 이 없어도 된다. 지금 코드 그대로 | 큰 프로젝트에서 느리고 디스크를 먹는다 | **1차 기본** |
| git(작업 전 상태를 임시 커밋 · stash 로 잡기) | 빠르다. 바뀐 것만 | 사람이 커밋 안 한 변경과 섞이기 쉽다. git 아닌 폴더는 못 쓴다 | 2차, git 레포에서 고를 수 있게 |

1차 폴더 복사 규칙:

- 기본 제외: `.git` · `node_modules` · `dist` · `build` · `.venv` · `__pycache__` · 프로젝트에 적은 제외 목록.
- 복사할 크기가 상한(기본 500MB)을 넘으면 **작업을 시작하지 않고** 이유를 보인다(제외 목록을 늘리라고).
- 되돌림은 **그 작업이 바꾼 것만**: 백업과 다른 파일을 백업으로, 작업 중 새로 생긴 파일은 `orphans/{작업}/` 로 옮긴다(지우지 않는다).
- 작업이 도는 동안 같은 폴더를 사람이 고치면 되돌림이 그것도 되돌린다 — 화면에 그렇게 적는다.

## 6. AI 에게 주는 것 (코드 메모)

- 작업 폴더(`cwd`)는 프로젝트 경로. `--add-dir` 로 그 경로와 메모 첨부 폴더만 연다.
- 지시 = 범용 `prompts/fix_system.md` + **프로젝트 경로의 `CLAUDE.md` · `AGENTS.md`**(있으면 클로드가 스스로 읽는다) + 프로젝트 설정의 "추가 지시"(선택).
  - 범용 지시는 "메모가 말한 것만 고친다 · 지울 것은 지우지 말고 `removed/` 로 옮긴다 · 못 하면 이유를 적는다 · 결과는 headline/detail 로" 정도. 교과 계약서 같은 도메인 규칙은 넣지 않는다.
- 막는 것(차시 작업대 실측 그대로): `--permission-mode acceptEdits` 는 작업 폴더 안의 `rm` · `mv` 를 허용 목록과 상관없이 자동 허락한다 →
  **거부 목록**으로 `rm` · `rmdir` · `del` · `git` 를 막는다. `--setting-sources project` 로 사용자 전역 설정의 허용 규칙을 물려받지 않는다.
- 끝난 뒤 **경로 밖 변경 감지**: 프로젝트가 git 레포면 상위 레포의 `git status`, 아니면 결과에 ⚠ 만. (차시 작업대도 gyo6 차시 폴더 밖 변경을 ⚠ 로 적었다.)
- 결과 형식: `{status: fixed|partial|not_done|needs_confirm, headline, detail, files}` — 지금 `desk_fix_output` 과 같은 모양.

## 7. 화면

```text
┌ 왼쪽 ─────────────┐ ┌ 가운데: 프로젝트 카드 ─────────────────────────────┐
│ [+ 프로젝트 추가] │ │ 이름 · 경로 · [경로 열기] [설정] [멈춤]            │
│ 묶음: 전체 · A · B│ │ 메모 적기 (종류 · 넣을 자리 · Ctrl+V 캡처) [적기] │
│ 프로젝트 목록     │ │ 대기열 — 위에서부터 처리                          │
│  ● 처리 중 / 대기 N│ │ ▾ 처리된 메모 N개 (여럿 볼 때 5개 높이 · 접기)    │
│ AI 모델 ▸         │ │ 작업 기록 · AI 사용량                             │
└──────────────────┘ └──────────────────────────────────────────────────┘
```

- [+ 프로젝트 추가]: 이름 · 경로(직접 붙여 넣기, 폴더가 있어야 받음) · 묶음(자유 글자) · 제외 목록 · 추가 지시.
- 같은 경로를 두 번 넣지 않는다. 한 경로가 다른 프로젝트 경로 **안**에 있으면 경고(같은 파일을 두 대기열이 고칠 수 있다).
- 지우기는 **목록에서만** 뺀다(프로젝트 폴더는 건드리지 않는다). 기록(`data/projects/{id}`)도 함께 지울지는 따로 묻는다.
- 위쪽 탭 · 사이드바 고정, 처리된 메모 5개 · 접기 등 최근에 다듬은 화면 동작은 그대로 가져온다.

## 10. 1차 구현에서 정한 것

- 외부 패키지 없이 **표준 라이브러리만** 쓴다(설치를 단순하게). 켜기는 `python -B -m memodesk` 또는 `MemoDesk.bat`.
- 화면 · 메모 · AI 결과 문구는 한국어. AI 의 `headline` · `detail` 은 **메모를 쓴 사람의 언어**로 쓰게 했다.
- 클로드는 **프로젝트 경로를 작업 폴더로** 돈다 — 그 폴더의 `CLAUDE.md` 를 스스로 읽는다. 열어 주는 다른 폴더는 첨부 그림 폴더와
  치운 파일 보관 폴더뿐(기록 폴더 `notes.json` 은 열지 않는다).
- 사람이 바꿀 수 있는 메모 상태는 완료 · 열림뿐(처리 중 · 대기는 처리기만 바꾼다).
- 실측(2026-10-14, Haiku): 메모 1건 12초 · $0.006. 지우기 요청은 `removed/` 로 옮겨졌고, [지금 멈춤]은 바뀐 것을 되돌리고 메모를 대기로 돌렸다.

## 11. 처음 쓰기 전 준비 (2026-10-14 사용자 요청)

> "맨처음에 바로 사용하는 게 아니라 그런 것들을 먼저 설정하고, 깔아야 하는 것들을 먼저 깔게끔 유도하거나 버튼을 클릭하면 깔아주는 기능"

- `Setup.bat` — 파이썬이 없으면 winget(`Python.Python.3.12`, 이 사용자에게만)으로 깔고 MemoDesk 를 켠다. 파이썬이 있어야 화면이 켜지므로 이것만 bat 이 한다.
- 화면의 **시작하기 전에** 점검표(`memodesk/setup.py`) — 파이썬 · Claude Code CLI · 클로드 로그인(필수) · Git for Windows(권장).
  준비가 안 됐으면 맨 위에 펼치고, 왼쪽 [환경 점검]으로 다시 연다. 버튼은 **보이는 새 창**에서 고정된 명령만 돌린다 —
  Claude Code 공식 설치(`irm https://claude.ai/install.ps1 | iex`), `claude auth login`, `winget install Git.Git`.
- 로그인 확인은 `claude auth status`(JSON, 비용 없음). 로컬 기록만 보므로 [실제로 불러 보기](Haiku 한 번)를 따로 둔다.
- 설치 직후에는 서버의 PATH 에 claude 가 없다 — 공식 설치 자리(`~/.local/bin`)도 찾고, 처리기는 찾은 경로를 작업에 넘긴다.
- CLI 가 없으면 처리기가 작업을 시작하지 않고 그 메모를 이유와 함께 열림으로 둔다.
- 출처: Claude Code 공식 설치 문서(code.claude.com/docs/en/setup) — Windows 설치 명령, Git for Windows 는 선택(권장), 무료 플랜 불가.
